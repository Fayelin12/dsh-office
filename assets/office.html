数据口径说明

会话状态

  • 进行中（🔵 转圈）：该会话的 agent 正在运行。
  • 待确认（⚠️ 举手）：该会话有待审批 / 待回答的交互。

会话 token

  • 单次输入 token（进行中会话）：最近一次请求的输入量 = 输入 + 缓存读 + 缓存写；三档分色：<10K 灰、10K~100K 蓝、>100K 黄。
  • 累计 token（历史会话）：该会话自创建以来所有回合的 输入 + 输出 + 缓存读 + 缓存写 之和。

列头 token

该列所有工作区会话的累计 token 之和（含归档会话）。

项目 / 任务

项目：该列分配的工作区数；任务：该列所有工作区的会话数（含归档会话）。

四态动画

  • 🟢 空闲：该列无进行中会话。
  • 🔵 工作：1~4 个进行中会话。
  • 🟠 忙疯：超过 4 个进行中会话。
  • 🔴 举手：存在待确认会话。

对话气泡

按状态 / 最近调用工具 / 会话标题关键词，匹配一句随机文案。
